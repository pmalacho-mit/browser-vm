# Python 3.12 playground

This is `/root/project` in a Linux VM running in your browser tab.

    python3 main.py            # run the example
    python3 main.py Ada        # with an argument
    python3                    # interactive interpreter
    pip install --user rich    # packages from PyPI (allowed by the network gate)

Edits you save here are what Python runs. Nothing is kept after you close the
tab, so download anything you want to keep.
