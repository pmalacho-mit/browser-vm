# Node.js 24 + Python 3.12 playground

This is `/root/project` in a Linux VM running in your browser tab.

    node index.js              # the JavaScript example
    python3 main.py            # the Python example
    npm install <package>      # from npm
    pip install --user <pkg>   # from PyPI

Nothing is kept after you close the tab, so download anything you want to keep.
